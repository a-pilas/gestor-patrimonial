Política de privacidad

Gestor patrimonial CELIANCA · Última actualización: 8 de noviembre de 2026

Qué es esta aplicación

Gestor patrimonial CELIANCA es una aplicación web de uso personal y familiar para llevar el seguimiento del patrimonio de una familia: cuentas, inversiones, inmuebles y deudas. Está en https://patrimonio.andrespilas.eu/. No es un servicio comercial ni está abierta al público.

Qué datos trata y dónde se guardan

La aplicación trata únicamente los datos que tú mismo introduces (por ejemplo, saldos, posiciones y movimientos). Esos datos se guardan:

  • En tu propio navegador (almacenamiento local del navegador), en el dispositivo que uses.
  • Opcionalmente, en tu propio Google Drive, si pulsas «Conectar con Google Drive». Se guardan en un único archivo llamado gestor-patrimonial-datos.json.

La aplicación no tiene servidor propio: el autor no recibe, no ve ni almacena tus datos en ningún sistema suyo.

Qué permiso pide a Google y para qué

Si conectas Google Drive, la aplicación solicita un único permiso: https://www.googleapis.com/auth/drive.file. Este permiso solo le deja ver y modificar los archivos que la propia aplicación crea o que tú le abres. No puede leer ni tocar el resto de tus archivos de Drive. Se usa exclusivamente para guardar y cargar el archivo de datos descrito arriba, de modo que tus datos estén sincronizados entre tus dispositivos.

El código de acceso de Google se conserva solo en la memoria de la pestaña del navegador mientras la usas; no se guarda en ningún sitio.

Uso limitado de los datos de Google

El uso que la aplicación hace de la información recibida de las API de Google se ajusta a la Política de datos de usuario de los servicios de API de Google, incluidos los requisitos de uso limitado. La información de tu Drive no se transfiere a terceros, no se usa para publicidad ni para entrenar modelos, y ninguna persona la lee salvo tú.

Con quién se comparten los datos

Con nadie. La aplicación no incluye analítica, publicidad ni cookies de seguimiento. Para funcionar, la página se descarga desde GitHub Pages y usa los servicios de Google que tú autorices (inicio de sesión y Drive); esos proveedores tratan los datos técnicos de la conexión según sus propias políticas.

Seguridad

Toda la comunicación se hace por HTTPS. La contraseña que protege la aplicación es un candado de pantalla, no un cifrado: el archivo de datos en tu Drive no está cifrado, por lo que te recomendamos proteger tu cuenta de Google con la verificación en dos pasos.

Conservación y eliminación de tus datos

  • Para borrar los datos de Drive, elimina el archivo gestor-patrimonial-datos.json de tu Drive.
  • Para revocar el acceso de la aplicación a tu cuenta, hazlo en myaccount.google.com/permissions.
  • Para borrar los datos locales, elimina los datos del sitio en la configuración de tu navegador.

Menores

La aplicación no está dirigida a menores de edad.

Cambios en esta política

Si esta política cambia, se actualizará en esta misma página con una nueva fecha.
